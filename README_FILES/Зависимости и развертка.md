# Развертка проекта

В папке с проектом:

```
make env
make up
```

Переходим на localhost в бразуере:

```
http://localhost:8080
```

У нас открывается веб-интерфейс проектав браузере

# Подтверждение email в режиме разработки

Если в `.env` не задан `SMTP_HOST`, письма никуда не отправляются, а выводятся в лог приложения. Код подтверждения после регистрации можно найти так:

```
make logs
```

Ищите строку `email (SMTP не настроен, письмо не отправлено)` — в ней есть текст письма с кодом.

Для настоящей отправки заполните в `.env` переменные `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` и перезапустите приложение (`make up`).
