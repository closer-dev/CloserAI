# Действия на пк

> [!IMPORTANT]
> Данное руководство актуально только для GnU/Linux, WSL и MacOS

Ставим git. Пример для арча:

```
sudo pacman -S git
```

На разных ОС это может отличаться, но принцип везде одинаковый.

Делаем все как на данном скриншоте:

Последняя команда выводит нам наш ssh-ключ. копируем его и переходим к действиям на github

# Действия на GitHub

Переходим в настройки аккаунта, в раздел ssh and gpg keys. Жмем кнопку "new ssh key"

<img width="1606" height="211" alt="Снимок экрана 2026-10-26 в 22 46 37" src="https://github.com/user-attachments/assets/8c8431d3-ad36-4156-9ef6-58d57068796b" />

У нас открывается следующее окно:

<img width="2048" height="1280" alt="Снимок экрана 2026-10-26 в 22 47 55" src="https://github.com/user-attachments/assets/3aea7976-c12e-4e29-a518-3cbfe3a49ea3" />

В графе title просто вбиваем название для ssh-ключа. Графу key type не трогаем. В графе key вставляем всю строку с ssh-ключем из терминала. Сохраняем. 

Потом клонируем репозиторий на устройство:

```

https://github.com/closer-dev/CloserAI.git

```

Если все сделано правильно, то логин и пароль у нас не запросит. Ждем конца процесса и приступаем к работе с репозиторием уже на устройстве
