# CloserAI — роли и зоны ответственности

**Общие правила владения:**
- Владелец модуля отвечает за него целиком: миграции и sqlc-запросы своих таблиц, сервис, хендлеры, тесты, документацию.
- DevOps проверяет каждую миграцию (индексы, `tenant_id`, обратная совместимость), но не пишет миграции за других.
- Модули общаются только через интерфейсы сервисов и `platform/eventbus` (правило из техплана). Интерфейсы на стыках согласуются до начала кода.
- Фронтенды сначала делают макет в Figma, согласуют его и только потом пишут код. Макет в Figma считается источником правды для UI.
- Этап считается закрытым, когда код прошёл ревью, есть тесты, задеплоен на стенд и QA принял сценарий.
